# Objective

PodWeaver will run on each user's system as a standalone application that can handle all incoming and outgoing data traffic for file transfer. It must ensure easy and quick peer discovery, regular checks to verify peer fairness and security against malicious peers.

## Implementation Plan

PodWeaver will be implemented in several phases, each phase will be tested individually before an integration step to combine the outputs of all phases into the final product.

Each phase will perform a task that does not depend on any other phase.
